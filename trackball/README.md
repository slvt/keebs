# Track Ball

A wired trackball with a PMW3389 sensor and an RP2040 Zero, running QMK with Vial. Works with two or three buttons, switchable in Vial.

Firmware source is in [QMK](QMK), the prebuilt Vial firmware is in [firmware](firmware).
